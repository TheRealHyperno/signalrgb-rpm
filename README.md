# signalrgb-rpm

Unofficial Fedora/RPM packaging for [SignalRGB](https://signalrgb.com), built from
the vendor's own Ubuntu `.deb` directly at build time. This was made because
SignalRGB's official `install.sh` only supports Arch and Debian/Ubuntu repos.

## How it works

1. `signalrgb.spec` points `Source0` at SignalRGB's apt pool URL
   (`https://pkgs.signalrgb.com/apt/pool/...`).
2. During build (locally, or on COPR), rpmbuild verifies the pinned SHA256 of
   the `.deb`, unwraps it with `ar` + `tar`, and copies the payload to the same
   paths the vendor's packages install to:
   - `/opt/signalrgb/` — app + their bundled Qt6/ffmpeg/ICU stack (private,
     loaded via `LD_LIBRARY_PATH` by the `/usr/bin/signalrgb` shim)
   - `/usr/bin/signalrgb`, `/etc/udev/rules.d/72-signalrgb.rules`,
     `/usr/share/applications/signalrgb.desktop`, hicolor icons
3. Dependency generation: bundled sonames are excluded from both auto-Provides
   and auto-Requires (they live in `/opt/signalrgb`, don't pollute the system
   namespace, and we don't want fake soname provides clashing with Fedora's
   qt6 packages). System soname Requires are generated by rpm's ELF scanner,
   so the package tracks real Fedora sonames, not hand-maintained guesses.
   Debian group names in the udev rules (`plugdev`, `i2c`) are created
   non-interactively in `%post` if missing; device access for the common cases
   rides on `TAG+="uaccess"` logind ACLs either way.

## Updating to a new upstream version

The version info in the spec (version, buildrev, sha256, soname filter list)
must be bumped deliberately. Run:

```sh
./update.sh          # prints what to change; runs daemon-happily against the stable channel
```

Then edit `signalrgb.spec` accordingly and bump any of:
- `Version:` and `%global buildrev`, `%global deb_sha256`
- `%global bundled_sonames` (only if upstream ships/removes bundled libraries)

Push to GitHub and COPR picks it up via webhook (source build), or kick a
rebuild from the COPR UI.

## Building locally

```sh
rpmbuild -bb signalrgb.spec   # with the .deb present under ~/rpmbuild/SOURCES
dnf install ~/path/to/signalrgb-2.5.86-*.rpm
```

## Installing from COPR

```sh
dnf copr enable <user>/signalrgb
dnf install signalrgb
```
